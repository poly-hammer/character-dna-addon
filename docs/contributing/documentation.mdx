These documents use Fumadocs and are published by the Poly Hammer documentation repository.

Read the repository agent instructions for the authoring contract. Configure a local source override in the central docs checkout, then run:

```sh
npm run docs:prepare
npm run docs:validate
npm run dev
```

Main-branch updates appear on staging. Stable releases publish versioned production documentation.
